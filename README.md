# davcandles — лендинг свечей для торта

Одностраничный сайт для мастера Дины (Instagram @davcandles): свечи для торта, бенто-свечи, подарочные сертификаты и обучение.

## Структура

```
index.html          — страница (10 блоков)
css/style.css       — стили
js/main.js          — интерактив (без библиотек)
img/                — изображения: WebP 480/960 + JPG-фолбэк, иконки, og-image
video/              — видео-история (H.264, faststart) + постер
favicon.svg, site.webmanifest
robots.txt, sitemap.xml, llms.txt — SEO и GEO (поиск нейросетями)
.htaccess           — сжатие и кеширование для Apache
```

## Блоки

1. Шапка с бургер-меню на мобильных
2. Первый экран: «торт», где возраст набирается свечами-шариками, огоньки можно задуть
3. Виды свечей: цифры-шарики, цветочные цифры, топперы, бенто
4. Конструктор микса по прайсу: считает сумму, копирует готовый заказ и открывает Direct
5. Галерея с фильтром по настроению и просмотром фото
6. История Дины с видео
7. Подарочный сертификат: интерактивный макет (кому, от кого, номинал, пожелание, оформление), скачивание PNG, заявка
8. Обучение: полный курс 1500 ₽ и мастер-класс 500 ₽
9. Отзывы со слайдером (с Авито)
10. Вопросы и ответы, контакты

## Перед публикацией

- Замените домен `https://davcandles.ru/` на настоящий в `index.html` (canonical, og:url, og:image, JSON-LD), `robots.txt`, `sitemap.xml`, `llms.txt`.
- Сверьте прайс в `js/main.js` (массив `CATALOG`) — цены взяты с фото прайса, часть позиций была нечитаемой и не включена (цифры-пончики, цифры с кристаллами и др.).
- Уточните условия сертификата (срок действия, формат) и ссылку на оплату обучения через Tribute — сейчас кнопки ведут в Telegram-канал.
- Блок с картой не добавлен: точного адреса нет (только Санкт-Петербург и доставка по России). Если появится адрес самовывоза — добавьте карту в футер.
- Проверка: страница работает с локального сервера (`python3 -m http.server`) и на любом статическом хостинге.
